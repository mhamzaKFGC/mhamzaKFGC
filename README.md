## About

I study machine learning under attack. My master's thesis broke Domain Generation Algorithm (DGA) classifiers with adversarial examples. That work exposed how fragile these detectors really are, and it set the direction for everything I do now: attack a system first, then use what breaks it to build the defense.

I currently work on Byzantine-robust Federated Learning. Malicious clients can poison a shared model through label flipping, sign flipping, magnitude scaling, or slower, intermittent attacks that hide inside normal training noise. Most defenses catch these by checking how similar a client's update looks to its neighbors. That signal misses attacks that scale a legitimate-looking direction to a malicious magnitude. I am building an aggregation method that scores both direction and magnitude together, not one or the other.

I teach undergraduates and run research projects with them alongside my own work. Explaining an attack to a student who has never seen one forces me to state it precisely, which usually sharpens my own thinking about it.
